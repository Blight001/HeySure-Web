# 角色动作图集 · actions-v3

六类角色的动作由内置 ImageGen 以对应 `town-character-*-v2.png` 为身份参考重新生成，
不再用静态方向图做整身位移伪动画。每张图都是透明背景的严格 4 列 × 5 行图集：

| 行 | 帧语义 |
| --- | --- |
| 0 | 正面行走 1–4 |
| 1 | 左侧行走 1–4 |
| 2 | 右侧行走 1–4 |
| 3 | 背面行走 1–4 |
| 4 | 待机、挥手、角色专属动作、躺姿 |

运行时 `src/generatedCharacters.ts` 扫描每格 alpha 边界，统一缩放到 64×96、脚底基线，
再交给既有 Phaser 动画契约（20 帧、行走 6 fps）。图集加载失败时仍回退到 v2 静态图。

## 生成约束

以每个 v2 角色图为参考，使用同一套约束：真实 4×5 透明动画图集、每格一个完整角色、
相邻行走帧必须有交替脚步与反向手臂摆动，保持服装/发型/道具/脸部身份、统一脚底基线，
禁止棋盘格、背景、网格线、文字、水印、裁切和重复角色。

专属动作仅改变第 5 行的第 3 帧：蓝=读笔记本，红=查看消息，黄=拧工具，灰=写笔记，
管理员=检查钥匙环，图书管理员=打开阅读书本；第 5 行第 4 帧为横向躺姿。
